# Bang

A Flash project.

## Layout

- `flash_project.json` — editor project marker
- `manifest.json` — game-layer asset manifest
- `assets/` — textures, locales, sprite sheets, etc.
- `mods/` — Lua mod packages
- `locales/` — game-layer locale catalogs

Edit `manifest.json` to declare assets; the editor's Asset
Browser will surface them.
